Privacy Policy

John Trading Desk · last updated 16 November 2026

Who uses this app

This app is used only by its owner, on the owner's own computer. It is not offered to anyone else.

Google data accessed

With the owner's consent, the app requests the read-only scope https://www.googleapis.com/auth/spreadsheets.readonly to read the owner's own trading journal spreadsheet. It does not create, edit or delete any Google data.

How the data is used

Spreadsheet values are read on demand to produce summaries for the owner. They are not sold, shared with third parties, used for advertising, or used to train general AI models.

Storage

OAuth tokens are stored only on the owner's computer. Spreadsheet data is not copied to any server operated by this app.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
